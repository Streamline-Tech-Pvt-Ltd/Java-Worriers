Q.2)type of variable?
-1.. Local Variable
    -Declared inside a method, constructor, or block.
    -Can only be used within that method or block.
    -It must be initialized before use.

2. Instance Variable (Non-static Variable)
  -Declared inside a class but outside any method.
  -Every object gets its own copy.
  -Created when an object is created.

3. Static Variable (Class Variable)
   -Declared using the static keyword.
   -Belongs to the class, not to objects.
   -Only one copy is shared by all objects.

Q.3)primitive data type and non privimitive data type?
-1. Primitive Data Types
    Primitive data types are predefined by Java and store actual values directly.

 2. Non-Primitive Data Types (Reference Data Types)
     Non-primitive data types are created by the programmer or provided by Java. They store references (addresses) to objects instead of the actual data.

Q.4)Why Java is not purely object-oriented?
-No. Java is not a purely object-oriented programming language because it supports 8 primitive data types (byte, short, int, long, float, double, char,          boolean), which are not objects. However, Java is considered an object-oriented programming language because it supports classes, objects, and the four        pillars of OOP: encapsulation, inheritance, polymorphism, and abstraction.


Q 5)Type Casting in Java?
-Type Casting is the process of converting one data type into another data type.

 1. Implicit Type Casting (Widening)
    -Done automatically by Java.
    -Converts a smaller data type to a larger data type.
    -No data loss.

2. Explicit Type Casting (Narrowing)
   -Done manually by the programmer.
   -Converts a larger data type to a smaller data type.
   -May cause data loss.

Q.7)what is control statement?
- A Control Statement is a statement that controls the flow of execution of a Java program. It decides which statements will execute, how many times they execute, and in what order.

1. Selection (Decision-Making) Statements

These statements execute code based on a condition.

Types:
if
if-else
else-if
nested if
switch
Example (if-else)
public class IfElseDemo {
    public static void main(String[] args) {
        int age = 18;

        if (age >= 18) {
            System.out.println("Eligible to vote");
        } else {
            System.out.println("Not eligible to vote");
        }
    }
}

Output:

Eligible to vote
2. Looping (Iteration) Statements

These statements execute a block of code repeatedly until a condition becomes false.

Types:
for
while
do-while
Example (for loop)
public class ForLoopDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}



3. Jump Statements

These statements change the normal flow of program execution.

Types:
break → Terminates the loop or switch.
continue → Skips the current iteration and moves to the next iteration.
return → Exits from a method.
Example (break)
public class BreakDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i == 3)
                break;

            System.out.println(i);
        }
    }
}

Q.8)What is Bytecode in Java?
-Bytecode is the intermediate code generated by the Java compiler (javac) after compiling a Java source file (.java). It is stored in a .class file and is executed by the Java Virtual Machine (JVM).
